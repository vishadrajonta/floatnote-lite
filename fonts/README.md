# Bundled fonts

Core families bundled with FloatNote, fetched with `scripts/fetch_fonts.py` from the official
[google/fonts](https://github.com/google/fonts) repository. Every folder keeps its licence file
(`OFL.txt` = SIL Open Font License 1.1, `LICENSE.txt` = Apache License 2.0); the script refuses
anything else. Uprights only, variable files where the family has them. `manifest.json` lists the files.

More families (about 120) are an optional download from inside the app (⌃⌥F, then ⌘D), with the same licence check.
Fonts installed on the Mac (including Adobe Fonts) are used in place and never copied here.
